# 👾Chatting-Ai
🧠 Chat-AI Jarvis

Chat-AI Jarvis is an interactive AI chat assistant built using the Gemini API with Google Search Grounding to deliver accurate, real-time answers.

💬 Type any question or query — Jarvis instantly responds with intelligent, grounded AI insights in a modern, responsive interface.


---

🚀 Features

⚡ Gemini-powered responses with Google Search grounding

🌐 Real-time web-based chat interface built using HTML, CSS, and JavaScript

💡 Dynamic and responsive design — works seamlessly across devices

🔍 Smart query handling for factual, up-to-date answers

🧩 Custom UI header + video background for an engaging experience



---

🛠️ Tech Stack

Frontend: HTML, CSS, JavaScript

Backend: Gemini API integration

Hosting: Netlify



---

🌟 About

Created by Dimal Parmar, Chat-AI Jarvis is a personal project inspired by the idea of blending conversational AI with live search data — bringing the power of Gemini AI into a sleek, web-based assistant.
